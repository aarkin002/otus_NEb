В кратце:

Внизу слева dhcp 2 области(настроены на маршрутизаторах выше) на правый и левый сегмент сети - разные, через VLAN, (+ssh, bpduguard, port security)

Выше 3 коммутатора LACP, STP

Выше 2 маршрутизатора HSRP (+ роутер на палочке)

В правой части NAT с перегрузкой, PAT, нат в 80 и 443 порты и ACL листы

Динамическая маршрутизация OSPF + статические маршруты в обеих частях
